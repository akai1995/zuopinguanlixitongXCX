## 3. 编码规范

### 3.1 TypeScript 规范

#### 3.1.1 类型定义

- **强制使用类型注解**：所有函数参数、返回值必须明确标注类型
- **接口命名**：使用 `I` 前缀，如 `IUserInfo`
- **类型别名**：使用 `T` 前缀，如 `TStatus`
- **避免使用 `any`**：仅在无法推断类型时使用 `unknown`

```typescript
// 推荐
interface IUserInfo {
  id: number
  name: string
  email: string
}

function getUserInfo(id: number): Promise<IUserInfo> {
  return api.getUser(id)
}

// 避免
function getUser(id: any): any {
  return api.getUser(id)
}
```

#### 3.1.2 变量命名

- **小驼峰命名**：普通变量、函数使用 `camelCase`
- **大驼峰命名**：类、接口、类型使用 `PascalCase`
- **常量命名**：全大写，下划线分隔，如 `MAX_SIZE`
- **私有属性**：使用 `_` 前缀，如 `_privateField`

### 3.2 Vue 组件规范

#### 3.2.1 组件命名

- **大驼峰命名**：组件文件名使用 `PascalCase`，如 `UserCard.vue`
- **语义化命名**：组件名应体现其功能，避免使用 `MyComponent` 等模糊命名

#### 3.2.2 脚本结构

使用 `<script setup lang="ts">` 语法糖，代码组织顺序：

1. 依赖导入（import）
2. 响应式声明（ref、reactive）
3. 计算属性（computed）
4. 生命周期钩子（onMounted、onUnmounted）
5. 方法定义

```vue
<script setup lang="ts">
import { ref, computed, onMounted } from 'vue'

const props = defineProps<{
  title: string
  count?: number
}>()

const emit = defineEmits<{
  (e: 'click', id: number): void
}>()

const isLoading = ref(false)

const displayCount = computed(() => props.count || 0)

onMounted(() => {
  initData()
})

async function initData() {
  isLoading.value = true
  // ...
}
</script>
```

### 3.3 样式规范

- **SCSS 语法**：使用 SCSS 预处理器
- **BEM 命名规范**：块（Block）- 元素（Element）- 修饰符（Modifier）
- **样式作用域**：使用 `scoped` 属性隔离样式

```scss
.user-card {
  background: #fff;
  
  &__title {
    font-size: 16px;
  }
  
  &--disabled {
    opacity: 0.5;
  }
}
```

## 4. 组件开发规范

### 4.1 组件分类

| 类型 | 说明 | 示例 |
| :--- | :--- | :--- |
| 基础组件 | 原子级组件，无业务逻辑 | Button、Input、Card |
| 业务组件 | 包含特定业务逻辑 | UserCard、OrderList |
| 页面组件 | 页面级组件，路由入口 | HomePage、ProfilePage |

### 4.2 组件设计原则

1. **单一职责**：每个组件只负责一件事
2. **可复用性**：避免硬编码，通过 props 传递配置
3. **无状态优先**：优先使用纯组件，状态由父组件管理
4. **事件驱动**：通过 emit 向父组件传递事件

### 4.3 Props 规范

- **必传属性**：标记为 required
- **默认值**：为可选属性提供合理默认值
- **类型校验**：使用 TypeScript 类型定义

```typescript
const props = defineProps<{
  title: string           // 必传
  count?: number         // 可选，默认 undefined
  size?: 'small' | 'medium' | 'large'
}>()

withDefaults(props, {
  count: 0,
  size: 'medium'
})
```

## 5. 状态管理规范

### 5.1 Store 结构

使用 Pinia 进行状态管理，按业务模块划分 store：

```
stores/
├── user.ts          # 用户状态
├── works.ts         # 作品数据
├── category.ts      # 分类管理
└── index.ts         # Store 导出入口
```

### 5.2 Store 命名规范

- **文件命名**：使用小写字母，下划线分隔，如 `user_store.ts`
- **Store ID**：与文件名一致，如 `user`
- **方法命名**：动作使用动词开头，如 `login()`、`fetchWorks()`

### 5.3 Store 使用示例

```typescript
import { defineStore } from 'pinia'
import { ref, computed } from 'vue'

export const useUserStore = defineStore('user', () => {
  const userInfo = ref<IUserInfo | null>(null)
  const token = ref('')

  const isLogin = computed(() => !!token.value)

  function login(credentials: ILoginForm) {
    // 登录逻辑
  }

  function logout() {
    userInfo.value = null
    token.value = ''
  }

  return {
    userInfo,
    token,
    isLogin,
    login,
    logout
  }
})
```

## 6. API 调用规范

### 6.1 API 目录结构

```
api/
├── user.ts          # 用户相关接口
├── works.ts         # 作品相关接口
├── category.ts      # 分类相关接口
└── index.ts         # API 导出入口
```

### 6.2 API 封装规范

- **统一封装**：使用 axios 或 uni.request 封装
- **错误处理**：统一处理 HTTP 错误和业务错误
- **请求拦截**：添加 token 等公共请求头
- **响应拦截**：统一处理响应数据格式

```typescript
import request from '@/utils/request'

export async function getUserInfo(id: number): Promise<IUserInfo> {
  const response = await request.get(`/users/${id}`)
  return response.data
}

export async function login(data: ILoginForm): Promise<ILoginResponse> {
  const response = await request.post('/auth/login', data)
  return response.data
}
```

### 6.3 错误处理规范

```typescript
try {
  const result = await api.login(form)
  // 成功处理
} catch (error) {
  if (error.response?.status === 401) {
    // 未授权处理
  } else {
    // 通用错误提示
    uni.showToast({
      title: error.message || '请求失败',
      icon: 'error'
    })
  }
}
```

  <view class="chart-container">
    <lime-echart :option="chartOption" />
  </view>

const props = defineProps<{
  data: IChartData[]
}>()

  series: [{ type: 'bar', data: props.data.map(item => item.value) }]

## 9. 登录认证规范

### 9.1 Token 管理

- **存储位置**：使用 `uni.setStorageSync` 存储 token
- **token 有效期**：后端返回过期时间，前端定时检查
- **自动刷新**：token 过期前自动刷新

### 9.2 登录状态检查

```typescript
import { useUserStore } from '@/stores/user'

export function requireAuth() {
  const userStore = useUserStore()
  
  if (!userStore.isLogin) {
    uni.navigateTo({ url: '/pages/login/index' })
    return false
  }
  return true
}
```
